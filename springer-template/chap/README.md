# 可选书稿部件

本目录保留参照模板提供的完整 SVMono 书稿结构，但不保留《高等代数学》的作者、
四版前言或十章正文。`dedication.tex`、`foreword.tex`、
`acknowledgement.tex`、`acronym.tex`、`part.tex`、`appendix.tex`、
`glossary.tex` 和 `solutions.tex` 是中性的结构样板；按需复制或从某个
`translations/<model>/frontmatter.tex`、`appendices.tex`、`backmatter.tex`
中载入。

`project-info.tex`、`preface.tex` 和 `references.tex` 是当前 Stacks Project
中文翻译共同使用的部件。
