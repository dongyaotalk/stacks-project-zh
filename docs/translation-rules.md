# 翻译与 LaTeX 约束

## 1. 忠实性原则

译文必须保持英文原文的数学含义、论证顺序、逻辑强度和引用关系。不得：

- 增加原文没有的解释、例子、假设或结论；
- 为了“更顺畅”而弱化或强化量词、条件、否定和唯一性；
- 修复疑似英文错误而不提交单独问题；
- 把译者注释混入正文；
- 删除重复、保留意见或看似不重要的限定词；
- 用模型常识替代当前英文提交中的具体陈述。

发现源文疑问时保持忠实翻译，并在 issue 中记录。明显影响正确性的源文问题必须
阻断发布。

## 2. 中文风格

详细规范见 `config/style-guide.md`。基本要求：

- 使用简体中文和现代数学书面语；
- 术语以 `config/glossary.yml` 的 `approved` 词条为准；
- 没有批准译法时报告术语，不临时创造后继续批量传播；
- 每一次数学术语出现都保留中英文，固定写成 `中文（English）`；此要求不是
  “首次出现规则”，同一术语重复出现时必须重复双语形式；
- 括号内保留该处英文原词形，复数、大小写或限定成分不得无依据改成另一词形；
- 句子可以按中文语序调整，但逻辑对应必须可逐句核查；
- 人名、书名和专有名词按词表或公认形式处理，必要时首次附英文；
- 不使用宣传式、聊天式、总结式或带评价色彩的模型语言。

## 3. 高危语义

以下内容必须逐项核对：

- `if`、`only if`、`if and only if`；
- `necessary`、`sufficient`；
- `at least`、`at most`、`exactly`；
- `all`、`every`、`some`、`any`、`unique`；
- `injective`、`surjective`、`bijective`；
- `finite`、`finite type`、`finite presentation`；
- `local`、`locally`、`global`；
- 否定词和否定作用域；
- 主体、客体、态射方向和复合顺序；
- `respectively` 的对应次序；
- 引用对象究竟是定义、命题、假设还是结论。

批评模型和人工数学审校都必须覆盖这些类别。

## 4. 禁止直接翻译原始 TeX

模型只接收自然语言节点及受保护占位符。解析器负责拆分和恢复：

```text
<MATH_0001>
<REF_0001>
<CITE_0001>
<LABEL_0001>
<URL_0001>
```

模型不得创建、删除、重命名、重排或拆开占位符。结构检查必须比较占位符多重集
和顺序；不一致时直接 `qa_status=FAIL`。

## 5. 命令和环境策略

`config/macro-policy.yml` 是机器可读基线。处理原则：

### 5.1 完全锁定

- 所有数学模式和数学环境；
- `\label`、`\ref`、`\eqref`、`\pageref`、`\cite`；
- 永久 Tag、引用键、URL 目标和文件路径；
- `verbatim`、xymatrix 结构及程序代码；
- `reference`、`slogan`、`history` 等上游编辑元数据。

### 5.2 翻译文本参数

- `\title`、`\section`、`\subsection`、`\subsubsection`；
- `\emph`、`\textit`、`\textbf`、`\footnote` 内的自然语言；
- `\href{URL}{显示文字}` 的第二个参数；
- 定理、定义、例子和证明环境中的自然语言节点。

外层命令和参数结构必须保持不变。

旧式字体声明 `\bf` 只允许显式分组的 `{\bf 自然语言}` 形式：把开组花括号、
声明及其分隔空白整体锁定为一个占位符，把对应的闭组花括号锁定为另一个占位符，
只翻译两者之间的自然语言。两个占位符必须保留原序，不能把整组文字作为不可译
内容，也不能改写为 `\textbf{...}`、扩大加粗范围或让声明越过原来的组边界。
例如 `{\bf not}` 中的否定词需要翻译，但加粗声明和分组结构原样恢复。
未分组的 `\bf` 仍然阻断单元；本规则不自动批准其他旧式字体命令。

### 5.3 特殊处理

- TeX 文本重音命令（如 `\'e`）由解析器连同其字符参数锁定为显示占位符；在
  双语术语英文部分恢复原命令，不得由模型改写、删除或转换为另一种拼写；
- `\index` 不能直接整参数翻译；应分别保存稳定索引键、中文显示文本和排序键。
- 表格只翻译文本单元格，不改变列数、对齐、跨行和数学单元格。
- 列表只翻译项目正文，不改变嵌套、计数器和标签。
- 图注可以翻译；图片路径、尺寸和锚点锁定。
- 未列入策略的命令或环境默认为 `block`，必须先更新宏策略并增加测试。

## 6. 标签和跨章引用

- 上游局部 `\label` 名称不得由模型修改。
- 合并整书时必须复现上游 `scripts/make_book.py` 的章节前缀规则。
- 引用显示文本可以按中文语序调整，但引用目标必须保持一致。
- 禁止把 `\ref` 替换成手写编号。
- 禁止根据当前 PDF 页码写死页码或章节号。
- 在不完整候选预览中，渲染器可以把尚无目标的 `\ref` 临时显示为链接到官方
  Stacks 永久页的 `Tag XXXX（待译）`；该行为只发生在生成层，翻译单元仍须保存
  原始 `\ref`。目标标签加入当前预览后必须自动恢复内部引用。

## 7. 翻译单元边界

建议单元长度为 300–1500 个英文单词，优先边界为标题、普通段落、定义、引理、
命题、定理、证明、注记和例子。过长证明可以拆分，但子单元必须共享父级 Tag 和
上下文，不得在公式、列表项或逻辑条件中间切断。

## 8. 模型输出合同

模型输出必须符合 Schema，只包含：

- `unit_id`；
- 与输入段对应的中文文本；
- 原样占位符；
- `term_occurrences`：按译文中每个 `中文（English）` 术语的文本顺序逐项记录，重复
  出现也必须重复记录；
- `unknown_terms`；
- 可选、简短、非正文的 `notes`。

禁止输出完整 TeX 文档、Markdown 解释、思维过程、质量自评或自行修改的术语表。
所有新候选必须使用 `prompts/README.md` 标记的当前生产版本；当前为
`translator-v2`。`translator-v1` 仅供历史复现和测试兼容，`assemble` 会拒绝用它
创建新候选。

## 9. 未翻译内容

自动检查应识别未说明的英文自然语言残留。以下内容可以保留英文，但必须能由节点
类型或词表解释：人名、文献题名、标准缩写、代码、URL、引用键和明确要求保留的
专名，以及按本规范置于双语术语全角括号内的英文。检测到其他英文时不得自动
删除，应报告具体单元和位置。自动检查必须逐项核对 `term_occurrences` 与译文中的
`中文（English）`，包括重复次数和出现顺序。
