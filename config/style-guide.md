# 中文翻译风格规范

## 1. 语言

- 使用简体中文和正式数学书面语。
- 以准确、清楚为先，不追求文学化改写。
- 不使用“显然可知”“众所周知”等原文没有的评价。
- 不添加总结、提示、学习建议、免责声明或模型口吻。
- 原文有意重复时不得仅为避免中文重复而删除信息。

## 2. 术语

- `config/glossary.yml` 中 `approved` 词条具有约束力。
- `proposed` 词条只能用于讨论，不能作为批量翻译依据。
- 一个术语有多个语境译法时，必须按词条条件选择。
- 不确定时保留候选译文并填写 `unknown_terms`，不得静默创造新译法。
- 每一次数学术语出现都必须写成 `中文（English）`，不得只在首次出现时附英文。
- 双语术语使用中文全角括号，中文与左括号之间不留空格；括号内保留该处英文
  原词形。标题、列表、图表、脚注和正文适用同一规则。
- 人名等非数学专名不强制双语；首次出现时是否附英文由词表决定。

## 3. 数学逻辑

- 完整保留量词、否定、条件、唯一性和存在性。
- “当且仅当”不得缩写为只表达一个方向的句式。
- “至少”“至多”“恰有”“任意”“某个”必须逐一对应。
- `respectively` 必须保持对象顺序；中文过长时可拆句，但不能改变配对。
- 定义中的术语和条件优先逐项对应，不为流畅合并不同条件。

## 4. 标点和排版

- 中文正文使用全角中文标点。
- 数学模式、命令、标签、引用键、URL 和代码内部保持原 ASCII 形式。
- 中文与行内数学之间不手工插入不可控空格，由排版层统一处理。
- 括号内是完整中文说明时使用中文标点；纯数学内容保留数学标点。
- 不在译文数据中写死页码、定理号或章节号。
- 不得仅为消除不完整候选预览中的孤行、寡行或大块页尾留白而压缩或改写忠实译文；
  这类分页会随相邻单元加入而变化。只有裁切、重叠、不可读或结构错误才构成翻译级阻断。

## 5. 结构名称

章节、定义、引理、命题、定理、推论、证明、注记、例和练习的显示名称由模板
统一设置。译文数据不重复手写环境标题，除非英文节点本身有显式标题参数。

## 6. 引用

- `\ref`、`\cite` 等目标不可修改。
- 引用前后的中文可以调整语序，但不得改变引用所支持的陈述。
- 文献作者和标题按项目词表或文献数据库决定，不凭模型记忆标准化。

## 7. 译者说明

正文默认不加入译者注。确有必要时使用独立、可识别的审校元数据或项目批准的
专用环境，并通过单独 PR 审查；模型无权自行加入。
